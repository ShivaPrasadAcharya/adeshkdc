  1. बायाँ तलको “Realtime Sync” button खोल्नुहोस्। आफ्नो नाम लेखी पहिलो device मा “नयाँ code” थिच्नुहोस्।
  2. देखिएको ३-अङ्कको passkey अर्को device मा नामसहित राखेर “Connect” थिच्नुहोस्। एउटै passkey मा अधिकतम ३ connector मात्र जोडिन सक्छन्।
  3. अब main form, filtered output, editable आदेश/फैसला preview र submitted history realtime sync हुन्छन्।
  4. “Connector chat” बाट सोही passkey मा जोडिएका user बीच text chat र file attachment पठाउन सकिन्छ; सन्देश/attachment बढीमा ९ घण्टा मात्र रहन्छ। Paperclip बाट बढीमा ५ MB file छानिन्छ। Chat मा extension सहित attached file को original नाम देखिन्छ र त्यसमा click गर्दा त्यही नाममा तुरुन्त download हुन्छ। Chat default dark mode मा खुल्छ र ☾/☀ बाट dark/light बदल्न सकिन्छ। दुवै दिशाबाट आउने नयाँ remote message मा in-page notification र unread badge देखिन्छ; 🔔 बाट browser notification अनुमति दिए system notification पनि आउँछ। Chat सधैँ नयाँ message तर्फ auto-scroll हुन्छ। Message box text अनुसार auto-wrap/auto-grow हुन्छ र सानो arrow button ले send गर्छ। Sender को message receiver device मा पुगेपछि ✓ र receiver ले chat खोली पढेपछि ✓✓ देखिन्छ।
  5. काम सकिएपछि “Disconnect” थिच्नुहोस्। पछिल्लो code यही browser मा मात्र सम्झिइन्छ।
